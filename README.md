# TimeGrip Android

The Android client for TimeGrip, a time tracker for projects. The main project (server and web client) lives at [andprov/timegrip](https://github.com/andprov/timegrip).

APKs are published under [Releases](https://github.com/andprov/timegrip-client/releases), and the installed app offers to update itself when a new version comes out.
